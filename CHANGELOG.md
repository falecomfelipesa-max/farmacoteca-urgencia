# Changelog

Todas as mudanças notáveis neste projeto serão documentadas aqui.

O formato segue [Keep a Changelog](https://keepachangelog.com/pt-BR/1.1.0/) e
o projeto adere ao [Versionamento Semântico](https://semver.org/lang/pt-BR/).

## [1.0.0] - 2026-05-31

### Adicionado
- 32 medicamentos do carrinho de emergência brasileiro com posologia adulto/pediátrica/gestante
- Busca instantânea por nome, sinônimo, classe e indicação
- 22 filtros por cenário clínico (PCR, choque, anafilaxia, etc.)
- **Calculadora de doses por peso** com persistência via localStorage
- Tabelas dinâmicas para drogas vasoativas (dobutamina, dopamina, adrenalina BIC)
- Fórmula de Parkland integrada (queimaduras)
- Cálculo de VIG pediátrica (Velocidade de Infusão de Glicose)
- Tema dark otimizado para uso noturno
- Layout responsivo (mobile-first)
- CSS de impressão configurado
- Atalhos de teclado (`/` para busca, `Esc` para fechar modal)
